# Базовые концепции

## Кадр

Игра работает на одном цикле `requestAnimationFrame`. Каждый кадр:

1. Собираются фронты ввода (`justDown` / `justUp`).
2. `dt` ограничивается `maxDelta` (по умолчанию `0.1` с) и умножается на `game.timeScale`.
3. Обновляются твины и таймеры сцены.
4. `scene.fixedUpdate(step)` выполняется ноль или несколько раз фиксированными шагами (`game.fixedStep`, по умолчанию 1/60 с, не более 8 шагов).
5. `scene.update(dt)` — один раз.
6. Обновляются все активные дочерние объекты (анимации, частицы, кнопки, джойстик, дети групп).
7. Обновляется камера (follow, тряска).
8. Физический мир делает свои фиксированные шаги (`physics.fixedStep`, по умолчанию 1/120 с) и разрешает коллайдеры.
9. Обновляются глобальные твины и таймеры.
10. Сцена рисуется, фронты ввода очищаются.

Если активных сцен несколько (`scene.launch`), шаги 3–8 выполняются для каждой работающей сцены в порядке `game.sceneStack` снизу вверх; `game.currentScene` — верхняя. Приостановленные и спящие сцены пропускаются, их тела заморожены.

Физика идёт **после** `scene.update`, поэтому скорости, выставленные в `update()`, применяются в этом же кадре и видны в отрисовке. Колбэки столкновений тоже срабатывают после `update()`.

## Единицы и координаты

| Что | Единица |
| --- | --- |
| Позиции, размеры, скорости | пиксели, пиксели/сек |
| Гравитация, ускорение, drag | пиксели/сек² |
| `dt` | секунды |
| Длительности твинов и таймеров | миллисекунды |
| Тряска/вспышка/затухание камеры | миллисекунды |
| `object.angle`, `setAngle`, углы частиц | градусы |
| `Math.angleBetween`, `distance`, векторы | радианы |

Начало координат — левый верхний угол, `y` растёт вниз. Холст имеет логический размер (`game.width`, `game.height`), браузер может масштабировать его через CSS; ввод пересчитывается обратно в логические координаты.

## Origin и трансформации

У каждого объекта есть `x`, `y`, `width`, `height`, `originX`, `originY`, `scaleX`, `scaleY`, `angle`, `alpha`, `visible`, `active`, `depth`, `blendMode`.

- Origin по умолчанию — **левый верхний угол** (`0, 0`), как в v1.0.
- `setOrigin(0.5)` центрирует отрисовку вокруг `x, y`, но не двигает физическое тело.
- `angle` в градусах, вращение вокруг origin.
- Отрицательный `scaleX/Y` отражает объект.
- `displayWidth = width * abs(scaleX)`, `centerX = x + displayWidth * originX`.
- Тело использует `object.x/y` плюс `body.offsetX/Y`; масштаб, угол и origin **не** меняют тело.

```js
const label = this.add.text(400, 40, 'По центру', { fontSize: 24 });
label.setOrigin(0.5, 0.5);
```

## Порядок отрисовки

Дети сцены сортируются по возрастанию `depth` (по умолчанию `0`), при равенстве сохраняется порядок добавления.

```js
this.background.setDepth(-100);
this.player.setDepth(10);
this.hud.setDepth(1000).setScrollFactor(0);
```

Объекты с `scrollFactorX === 0` и `scrollFactorY === 0` рисуются вторым проходом **после** мировых объектов, в экранных координатах. Это HUD: он не зависит от позиции, зума и тряски камеры. Сортировка по depth идёт отдельно внутри мирового прохода и внутри HUD-прохода, поэтому HUD с depth `-5` всё равно выше мирового объекта с depth `9999`.

Контейнеры и группы сортируют своих детей по depth. Трансформация контейнера применяется к детям; группа — плоская коллекция в мировых координатах.

## Объект и тело

`GameObject` существует без физики. `enablePhysics()` создаёт `Body` и регистрирует его в общем `PhysicsWorld`.

```js
const box = this.add.rect(100, 100, 40, 40, '#89b4fa');
box.setVelocity(120, 0);        // тело создаётся автоматически
box.body.bounce = 0.6;
box.enablePhysics({ immovable: true }); // заменит автосозданное тело
```

Удобные методы (`setVelocity`, `setGravityY`, `setBounce`, `setImmovable`, `setCollideWorldBounds` и т.д.) создают тело при первом вызове. Благодаря этому код v1.0 продолжает работать.

## Жизненный цикл и очистка

```js
class Level extends Chroms.Scene {
  init(data) {}
  preload() {}
  create() {}
  update(dt) {}
  fixedUpdate(step) {}
  shutdown() {}
}
```

- `create()` вызывается один раз за активацию, после загрузки ассетов из `preload()` (или сразу, если очередь пуста).
- `shutdown()` вызывается перед уничтожением объектов сцены. Здесь снимайте DOM-обработчики и внешние подписки.
- Переключение сцены **уничтожает** всех детей сцены, тела, твины и таймеры сцены. Ничего не переживает рестарт.
- `game.tweens`, `game.time`, `game.anims`, `game.storage`, `game.sound`, `game.load` и физический мир — глобальные, они сохраняются.
- Гравитация, границы и коллайдеры мира сохраняются до изменения; тела и коллайдеры сцены удаляются автоматически.

## Время

`dt` уже учитывает `game.timeScale`. Дополнительные шкалы независимы:

```js
game.setTimeScale(0.5);      // замедление всей игры
game.tweens.timeScale = 2;   // твины в два раза быстрее
scene.time.timeScale = 0.5;  // таймеры сцены медленнее
physics.timeScale = 0.25;    // только физика
```

`scene.time` — таймеры сцены (`TimerManager`), `game.time` — глобальные. Аналогично `scene.tweens` и `game.tweens`.

## События

Игра, сцена, игровые объекты, ввод и звук поддерживают `on`, `once`, `off`, `emit`.

```js
this.events.on('update', (dt) => {});
this.player.events.on('destroy', (object) => {});
this.player.events.on('collide', (other) => {});
this.game.events.on('scene-create', (scene) => {});
this.game.events.once('ready', (game) => {});
```

Таблицы событий — в [game-and-scenes.md](game-and-scenes.md), [input-and-physics.md](input-and-physics.md) и [assets-audio-storage.md](assets-audio-storage.md).

## Пауза

- `game.pause()` замораживает симуляцию, твины, таймеры и физику всех сцен, но продолжает рендер. Фронты ввода всё равно очищаются каждый кадр.
- `scene.pause()` замораживает только `_update` этой сцены и шаг физики; рендер продолжается.
- `scene.sleep()` дополнительно скрывает камеру (`camera.visible = false`), `wake()` возвращает.
- `game.pauseOnHidden` (по умолчанию `true`) пропускает симуляцию при `document.hidden`.

Чтобы снять паузу по клавише (пока `scene.update` не работает), используйте DOM-обработчик:

```js
this._pauseKey = (e) => {
  if (e.code === 'Escape') game.togglePause();
};
window.addEventListener('keydown', this._pauseKey);
// снять в shutdown()
```

## Детерминизм

Тайминг кадра недетерминирован, а игровой рандом можно сделать воспроизводимым:

```js
const rng = new Chroms.Random(1234); // или game.random при config.seed
rng.int(1, 6);
rng.pick(['a', 'b']);
rng.shuffle(array);
```

`Chroms.Math` использует `Math.random`; для повторяемых последовательностей берите `Random`.
